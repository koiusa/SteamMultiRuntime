# Current Targeting System Sample

Open `TargetingSystem.unity` and enter Play Mode. The scene builds a current-generation
`TargetingController`, three registered targets, and the UI Toolkit target indicator.

Keyboard controls:

- Enter: toggle Single targeting
- E: toggle Multi targeting
- Ctrl: select all candidates while in Multi mode
- 1 / 2: select previous / next target
- C: clear targeting

The sample does not use the removed Binder, Camera Rig, legacy Input, or debug-material paths.
